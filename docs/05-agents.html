⏱️ Module Overview

Estimated time: 20 minutes

In this module, you'll create an AI Agent that can answer questions from both your document collection (via Cortex Search) and your revenue data (via Cortex Analyst).

💡 What is an AI Agent? An Agent is an AI orchestrator that decides which tools to use based on the user's question. It's like a smart assistant that knows when to search documents vs. query databases.

Choose Your Path

This workshop supports two agent options. Complete Option A or Option B (or both if time permits):

Option Description Best For
Option A: Cortex Agent Native Snowflake agent, runs entirely in Snowflake Snowflake-first teams, simplest setup
Option B: Bedrock Agent AWS agent with Lambda functions calling Snowflake AWS-first teams, access to Claude/Titan models

Select Your Agent Type

Option A: Snowflake Cortex Agent

The Cortex Agent orchestrates tools natively within Snowflake. We'll give it two tools:

  • fomc_search: Searches FOMC meeting documents
  • revenue_analyst: Queries revenue data via Semantic View

Step 1: Create the Agent

USE DATABASE WORKSHOP_DB;
USE SCHEMA AGENTS;

-- Create the Cortex Agent
CREATE OR REPLACE CORTEX AGENT WORKSHOP_AGENT
    MODEL = 'claude-3-5-sonnet'
    TOOLS = (
        -- Tool 1: Search FOMC documents
        {
            'name': 'fomc_search',
            'type': 'cortex_search',
            'description': 'Search Federal Reserve FOMC meeting documents for information about monetary policy, inflation, interest rates, and economic outlook.',
            'service': 'WORKSHOP_DB.PUBLIC.FOMC_SEARCH_SERVICE'
        },
        -- Tool 2: Query revenue data
        {
            'name': 'revenue_analyst',
            'type': 'cortex_analyst',
            'description': 'Query company revenue, profit, and sales data by time period, product line, or region.',
            'semantic_view': 'WORKSHOP_DB.REVENUE_TIMESERIES.REVENUE_SEMANTIC_VIEW'
        }
    )
    SYSTEM_PROMPT = $$
You are a helpful business analyst assistant. You help users find information 
from two sources:

1. FOMC Documents: Federal Reserve meeting minutes containing discussions about 
   monetary policy, inflation, interest rates, and economic conditions.
   
2. Revenue Data: Company financial data including daily revenue, costs, profit, 
   and breakdowns by product and region.

When answering questions:
- For questions about the Fed, inflation, interest rates, or economic policy, 
  use the fomc_search tool
- For questions about revenue, profit, sales, products, or regions, use the 
  revenue_analyst tool
- Always cite your sources
- If a question requires both sources, use both tools and synthesize the answer
$$;

Step 2: Test the Agent

-- Test: Ask about documents
SELECT SNOWFLAKE.CORTEX.AGENT(
    'WORKSHOP_DB.AGENTS.WORKSHOP_AGENT',
    'What did the Federal Reserve say about inflation in recent meetings?'
) AS RESPONSE;

-- Test: Ask about data
SELECT SNOWFLAKE.CORTEX.AGENT(
    'WORKSHOP_DB.AGENTS.WORKSHOP_AGENT',
    'What was our total revenue last month by region?'
) AS RESPONSE;

-- Test: Combined question
SELECT SNOWFLAKE.CORTEX.AGENT(
    'WORKSHOP_DB.AGENTS.WORKSHOP_AGENT',
    'Given the Fed''s recent stance on interest rates, how might that impact our revenue forecasts?'
) AS RESPONSE;
✅ Cortex Agent Complete! Your agent can now answer questions from both documents and structured data. Skip to "Test Your Agent" below or try Option B as well.

Option B: Amazon Bedrock Agent

This option creates a Bedrock Agent in AWS that calls back to Snowflake for data. It demonstrates cross-cloud integration.

Step 1: Deploy CloudFormation Stack

First, we'll deploy the AWS infrastructure using CloudFormation.

  1. In your AWS Console, go to CloudFormation
  2. Click Create stack → With new resources
  3. Select Upload a template file
  4. Upload the file aws/bedrock_agent_stack.yaml from the workshop repo
  5. Fill in the parameters:
    • SnowflakeAccountId: Your Snowflake account identifier
    • SnowflakeUser: Your Snowflake username
    • SnowflakePassword: Your Snowflake password (stored in Secrets Manager)
  6. Click through and Create stack
⏱️ Note: Stack creation takes 5-10 minutes. Wait for status: CREATE_COMPLETE.

Step 2: Create External Access in Snowflake

Allow Snowflake to call the Bedrock Agent:

USE DATABASE WORKSHOP_DB;
USE SCHEMA AGENTS;

-- Create network rule for AWS Bedrock
CREATE OR REPLACE NETWORK RULE BEDROCK_NETWORK_RULE
    MODE = EGRESS
    TYPE = HOST_PORT
    VALUE_LIST = ('bedrock-agent-runtime.us-west-2.amazonaws.com:443');

-- Create secret for AWS credentials
-- Get these from your CloudFormation outputs
CREATE OR REPLACE SECRET AWS_CREDENTIALS
    TYPE = GENERIC_STRING
    SECRET_STRING = '{"access_key_id": "YOUR_ACCESS_KEY", "secret_access_key": "YOUR_SECRET_KEY"}';

-- Create external access integration
CREATE OR REPLACE EXTERNAL ACCESS INTEGRATION BEDROCK_ACCESS
    ALLOWED_NETWORK_RULES = (BEDROCK_NETWORK_RULE)
    ALLOWED_AUTHENTICATION_SECRETS = (AWS_CREDENTIALS)
    ENABLED = TRUE;

Step 3: Create Bedrock Agent Function

-- Function to invoke Bedrock Agent from Snowflake
CREATE OR REPLACE FUNCTION INVOKE_BEDROCK_AGENT(
    user_query VARCHAR,
    session_id VARCHAR DEFAULT NULL
)
RETURNS VARIANT
LANGUAGE PYTHON
RUNTIME_VERSION = '3.11'
PACKAGES = ('boto3', 'snowflake-snowpark-python')
HANDLER = 'invoke_agent'
EXTERNAL_ACCESS_INTEGRATIONS = (BEDROCK_ACCESS)
SECRETS = ('cred' = AWS_CREDENTIALS)
AS
$$
import boto3
import json
import _snowflake
import uuid

def invoke_agent(user_query, session_id):
    # Get AWS credentials from Snowflake secret
    creds = json.loads(_snowflake.get_generic_secret_string('cred'))
    
    # Create Bedrock Agent Runtime client
    client = boto3.client(
        'bedrock-agent-runtime',
        region_name='us-west-2',
        aws_access_key_id=creds['access_key_id'],
        aws_secret_access_key=creds['secret_access_key']
    )
    
    # Generate session ID if not provided
    if not session_id:
        session_id = str(uuid.uuid4())
    
    # Invoke the agent (get Agent ID from CloudFormation outputs)
    response = client.invoke_agent(
        agentId='YOUR_AGENT_ID',
        agentAliasId='YOUR_ALIAS_ID',
        sessionId=session_id,
        inputText=user_query
    )
    
    # Collect response chunks
    result_text = ""
    for event in response['completion']:
        if 'chunk' in event:
            result_text += event['chunk']['bytes'].decode('utf-8')
    
    return {"response": result_text, "session_id": session_id}
$$;

Step 4: Test Bedrock Agent

-- Test the Bedrock Agent
SELECT INVOKE_BEDROCK_AGENT(
    'What are the recent trends in our revenue by region?'
) AS RESPONSE;
✅ Bedrock Agent Complete! Your Bedrock Agent is now integrated with Snowflake.
