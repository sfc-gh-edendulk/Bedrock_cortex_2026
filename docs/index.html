👋 Welcome!

In this hands-on workshop, you'll build a conversational AI application that combines the power of Snowflake Cortex and Amazon Bedrock to answer questions from multiple data sources using natural language.

🎯 What You'll Build: A chat application that can answer questions about Federal Reserve meeting documents AND analyze company revenue data—all through a single conversational interface.
