⏱️ Module Overview

Estimated time: 5 minutes

This module guides you through cleaning up the resources created during the workshop to avoid unnecessary charges.

⚠️ Important: Only perform cleanup when you're completely done with the workshop and don't need the resources anymore. This action is irreversible.

Option 1: Keep Your Trial Account

If you want to continue exploring Snowflake after the workshop, you can keep your trial account active. Your trial includes $400 in credits valid for 30 days.

To Minimize Costs While Keeping Data:

  • Suspend the warehouse when not in use (it auto-suspends after 2 minutes of inactivity)
  • Drop the Cortex Search service if not needed (it has ongoing compute costs)
-- Suspend warehouse to stop compute charges
ALTER WAREHOUSE WORKSHOP_WH SUSPEND;

-- Drop search service to stop indexing costs (optional)
DROP CORTEX SEARCH SERVICE IF EXISTS WORKSHOP_DB.PUBLIC.FOMC_SEARCH_SERVICE;

Option 2: Complete Snowflake Cleanup

To remove all workshop resources from Snowflake:

USE ROLE ACCOUNTADMIN;

-- Drop the Cortex Agent
DROP CORTEX AGENT IF EXISTS WORKSHOP_DB.AGENTS.WORKSHOP_AGENT;

-- Drop the Cortex Search Service
DROP CORTEX SEARCH SERVICE IF EXISTS WORKSHOP_DB.PUBLIC.FOMC_SEARCH_SERVICE;

-- Drop the Semantic View
DROP SEMANTIC VIEW IF EXISTS WORKSHOP_DB.REVENUE_TIMESERIES.REVENUE_SEMANTIC_VIEW;

-- Drop External Access Integration (if created for Bedrock)
DROP INTEGRATION IF EXISTS BEDROCK_ACCESS;

-- Drop Secrets (if created)
DROP SECRET IF EXISTS WORKSHOP_DB.AGENTS.AWS_CREDENTIALS;

-- Drop the entire database (removes all tables, stages, functions)
DROP DATABASE IF EXISTS WORKSHOP_DB;

-- Drop the warehouse
DROP WAREHOUSE IF EXISTS WORKSHOP_WH;
⚠️ Warning: Dropping the database will permanently delete all data, including the parsed documents, revenue tables, and any notebooks or Streamlit apps stored in the database.

Option 3: AWS Cleanup

If you deployed the Bedrock Agent CloudFormation stack, you should clean it up to avoid AWS charges:

Delete CloudFormation Stack

  1. Go to the AWS Console → CloudFormation
  2. Select the stack you created (e.g., workshop-bedrock-agent)
  3. Click Delete
  4. Confirm the deletion
💡 Note: The CloudFormation delete will remove:
  • Bedrock Agent and Action Groups
  • Lambda functions
  • IAM roles and policies
  • Secrets Manager secrets

Workshop Studio Accounts

If you used AWS Workshop Studio, your temporary AWS account will be automatically cleaned up after the workshop event ends. No action required.

Option 4: Keep Everything for Later

If you want to revisit this workshop later, you can:

  1. Keep your Snowflake trial - You have 30 days and $400 credits
  2. Suspend the warehouse - No charges when suspended
  3. Bookmark your account URL - Find it in your confirmation email
  4. Export any notebooks or apps - Download them for backup
💡 Tip: You can always recreate everything by running through the workshop again using the SQL scripts and code provided.
